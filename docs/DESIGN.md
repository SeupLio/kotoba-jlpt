# 产品与交互设计说明

本文记录「言葉 Kotoba」的设计取舍，重点说明**与参考产品（不背单词、MOJi 辞书）的差异**，
既是为了避免视觉与交互上的雷同，也是为了让每个设计决定都有可追溯的理由。

---

## 1. 设计目标

| 目标 | 具体含义 | 反面（要避免的） |
|---|---|---|
| 降低启动成本 | 打开就能开始，三步引导后直接进入今日计划 | 首页堆满运营位与课程推荐 |
| 让"会了"可信 | 判定标准严格且可解释，用户知道自己为什么被判定为熟练 | 自评"认识"就过关 |
| 让复习可预期 | 今天要做多少、未来一周有多少复习、为什么，都能看到数字 | 一个笼统的"待复习 137 个" |
| 不打断节奏 | 答题-反馈-下一题形成肌肉记忆，键盘/触屏都能盲操 | 每题都要滑一下、点两次 |
| 错了能改 | 手滑选错可以撤销，不让一次误触毁掉连击与统计 | 提交即落库，错了只能认 |

## 2. 视觉语言：和纸 + 朱红 + 墨色

参考产品的视觉偏"卡片化的学习工具"：不背单词用高饱和插画与拟物卡片，MOJi 用清爽的蓝白信息流。
本项目**刻意避开这两条路线**，改用一套更接近纸质辞书的语言：

| 元素 | 取值 | 理由 |
|---|---|---|
| 底色 | `#f6f2ea`（和纸白） | 长时间阅读降低对比刺激；与纯白相比更"纸感" |
| 主色 | `#c0392b`（朱红） | 取日式印章/朱批的意象，用于强调与进度，不使用参考产品的蓝/橙主色 |
| 辅色 | `#2f6f8f`（蓝） | 只用于"复习/信息"类语义，与朱红形成冷暖分工 |
| 文字 | `#2c2a26`（墨色） | 非纯黑，避免 OLED 上的硬边 |
| 成功/警告 | `#3f8a5b` / `#c88a1e` | 只用于反馈与提醒，不参与主视觉 |
| 圆角 | 22px（大卡 / 学习卡）/ 16px（卡片）/ 11px（控件） | 与纸质卡片、印章的圆润感一致 |
| 阴影 | 双层柔和阴影 + hover 提升 | 不做参考产品那种厚独立体卡片 |
| 图标 | **自绘 SVG**（`components/icons.tsx`），无第三方图标资产 | 规避图标库授权问题，也避免与参考产品的图标风格撞脸 |
| 字体 | 系统字体栈（含日文字体回退） | 保证汉字/假名在各平台都有正确字形 |

深浅两套主题共用同一组 CSS 变量，切换时只替换变量，不做两套布局。深色主题的朱红会提亮到
`#e0604f`，保证在深底上的可读性。

### 2.1 品牌与个性化

- **Logo**：墨色圆角方牌 + 朱红日轮 + 展开的和纸书页，对应「言葉」（语言 / 词）与「把词读进书里」。
  Web 顶栏、引导页、PWA 图标与 Android 自适应图标使用同一套几何；不使用第三方图形资产。
- **强调色**：朱、靛、松、梅四套，只替换主色与辅色语义，不改版式与品牌图形；深色主题各有对应的提亮色。
- **和纸纹理**：固定层纸纹与角落柔光，可关闭；不影响正文对比度。
- **沉浸背景**：学习页隐藏导航与顶栏，背景随强调色渐变，并叠加淡淡的竖排「言葉」水印；可关闭。
- **大字模式**：只放大题干、选项、释义等阅读对象，不改变信息层级；适合小屏与长时间阅读。
- **首页 masthead**：问候语 + 日期 + 品牌印章「一日一語」，让首页从“任务面板”变成有呼吸感的起点。

所有外观设置写入 `Settings`，随导出备份一起迁移；`<html>` 上的 `data-theme` / `data-accent` /
`data-paper` / `data-immersive` / `data-large-type` 是唯一开关，不维护多套布局。

## 3. 信息架构

首次打开是三步引导，之后进入五个一级页面；学习页独立全屏：

```
新手引导（Onboarding）
  1. 选 JLPT 等级（可多选）
  2. 每天新学多少词
  3. 目标考试日期（可跳过）
        ↓
今日（Home）        今天要做什么：考试倒计时/配速、进度环、易错词、7 天复习负载、等级进度
├─ 学习（Study）    全屏：新词预习 → 答题 → 反馈/撤销 → 结算；不显示底部导航
├─ 词库（Wordbook） 搜索、按状态/等级/词性筛选、易错筛选、逐词详情与易混词
├─ 统计（Stats）    累计、14 天学习量、留存预测、等级进度、记忆分布、60 天热力图
└─ 设置（Settings） 等级与每日量、考试日期、掌握规则、题型、显示/语音、备份
```

**为什么学习页要脱离导航**：答题时误触底部导航会丢失当前题目与计时。学习页改为全屏 + 显式退出按钮，
退出时自动提交当前题目并结算，不丢进度。

**为什么引导要问考试日期**：这是唯一能把"每天背多少"从拍脑袋变成可计算配速的输入。
不设日期也能正常使用，首页只是不显示倒计时。

## 4. 答题流设计

### 4.1 一个词的生命周期

```
新词预习卡（形 / 音 / 词性 / 多义项 / 例句，可听发音、可标为已会）
  → 后移至少 4 个队列位置（先看几个别的词）
  → 新学题型（认义、听音、例句填空）
  → 答对继续换题型；答错换题型、隔 3~5 题重练
  → 连击达标但未跨天：「待明日验证」，当天不再追问
  → 次日验证 → 进入复习池
  → 艾宾浩斯间隔复习
```

预习卡只在第一次见到该词时出现，**不占用答题次数**。这是对"没学过就被考"的修正：
先建立第一印象，再测回忆，答对率与挫败感都会更好。

点「记住了」后，当前词会被后移至少 4 个位置；连续预习一组新词时，会先形成约 5 个新词的滚动窗口，
再逐个回来作答。这样测验考的是间隔后的回忆，而不是上一秒刚看过的答案。按钮文案也明确写出
「记住了，先看后面的词」，让用户知道接下来会发生什么。

### 4.2 单题生命周期

```
呈现题目 → 作答 → 判定 → 反馈（对/错 + 正确答案 + 词条详情 + 连击进度）→ 下一个
```

反馈区固定包含三件事：**判定结果**、**正确答案**（答错时）、**词条完整信息**（读音、释义、例句、易混淆词）。
这样答错的词不需要再跳去别的页面查，减少一次上下文切换。

提交后进度先暂存在内存，点「下一个」才真正落库；因此反馈阶段可以点「撤销」重答同一题。
撤销会同时移除本次答错插入的重练题，不会污染队列。

### 4.3 答错后的处理

不是简单"再显示一遍"，而是：

1. 该词 `streak` 归零；
2. 换一**种题型**重新插入队列（位置在当前题后第 3~5 题）；
3. 同一个词一天内最多出现 `maxRepeatPerWord`（默认 3）次，防止卡在一个词上；
4. 若中途退出，该词约 10 分钟后到期，下次进入计划继续练。

换题型是关键设计：同一个词用「看日文选中文」答错，再用同一题型问一遍，用户可能只是记住了选项位置；
换成「听读音拼写」才能验证是否真的建立了形—音—义联结。

### 4.4 结算页

一轮结束（队列答完或主动退出）进入结算页，回答四个问题：正确率、新学词数、复习/巩固数、新熟练数、用时。
下方列出本轮新词、需要再看一遍的词、已会跳过的词，并提供「返回首页」「查看统计」。
词义展示首条常见释义（加粗）与次条释义，避免一行里塞满所有义项。
结算不是"庆祝动画"，而是让用户知道这一轮到底收获了什么、哪些词值得再碰一次。

### 4.5 键盘与触屏双通道

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 选择选项 | `1`–`6` | 点按选项卡片 |
| 提交拼写 | `Enter` | 点"提交" |
| 下一题 | `Enter` / `Space` | 点"下一个" |
| 撤销 | `U` / `Ctrl(Cmd)+Z` | 点"撤销" |
| 看答案 | `H` | 点"不会，看答案" |
| 朗读 | `R` | 点喇叭按钮 |
| 预习进入下一词 | `Enter` | 点"记住了，先看后面的词" |

触屏上所有可点区域最小 44×44 px，选择题选项整块可点。触屏不依赖 hover 表达状态，
选中/正确/错误由独立样式承担，避免点击后 hover 残留导致按钮"看起来没生效"。

### 4.6 发音策略：只把假名交给 TTS

单词详情、反馈区与听力题的所有朗读，都传入**假名**而不是汉字词形。原因是系统 TTS/Web Speech
对日语多音字并不可靠：`生` 可能被读成 `なま`，`人` 可能读成 `にん`。假名是读音的确定表示，
交给引擎后不存在歧义。可选地展示音调信息，但不把"音调是否准确"作为承诺——音调实现取决于系统语音包。

听力题在没有日语语音时会被整个剔除（而不是保留一个没有声音的题），并在设置页给出说明。
这是"宁可少一种题型，也不出死题"的取舍。

## 5. 首页：把"今天该做什么"算清楚

首页信息按"决策优先级"排列：

1. **考试配速卡**（设了考试日期才出现）：距考试天数、按当前每日新词数能否覆盖剩余词、建议每日词数、已掌握进度。
   配速跟不上时按钮变成「调高」，点进设置调整；跟得上时是「调整」。
2. **今日进度环**：剩余题量、预计用时、连续打卡；主按钮「开始学习」，次按钮「只复习」。
3. **三项统计**：已掌握 / 学习中 / 未学习。
4. **易错词卡**：近期连续答错或反复遗忘的词，直接给「专项练习」入口，不必先跳词库。
5. **未来 7 天复习负载**：把"以后会不会突然堆爆"提前展示；今天这一列包含逾期词。
6. **等级选择与进度**：快速切换等级，看到每个等级的掌握比例。
7. **今日概览**：新学/复习额度、待明日验证、备份提醒等。

这张页面刻意没有课程、资讯、排行榜。对个人学习工具来说，首页只该回答一句话：
**现在点哪里，今天做什么。**

## 6. 统计页的设计意图

统计不是"给你看好看的图"，而是回答五个问题：

1. **我累计做了多少？** → 累计作答、总正确率、连续打卡
2. **最近有没有断？** → 近 14 天学习量柱状图
3. **我记住多少？** → 记忆留存预测曲线（仅统计已掌握词）
4. **各等级进展如何？** → 分级进度条
5. **记忆强度怎么分布？** → 四档留存分布 + 近 60 天热力图

`all` 统计会排除"未学"和"已会跳过"的词；留存预测只基于已掌握词，避免把"没学过"误算成"忘了"。
图表全部用原生 SVG 手绘（`BarChart` / `LineChart` / `Buckets` / `Heatmap`），不引入图表库——
包体积更小，且样式能完全跟随主题变量。

## 7. 与参考产品的差异化对照

| 维度 | 参考产品的常见做法 | 本项目做法 |
|---|---|---|
| 视觉 | 高饱和插画 / 蓝白信息流 | 和纸底色 + 朱红 + 墨色，自绘 SVG 图标 |
| 熟练判定 | 单次记忆或自评 | 连续 3 次 + 跨 2 天，规则在设置页可解释、可调 |
| 复习调度 | 统一间隔曲线 | 每词独立 ease，叠加逾期惩罚三档 |
| 干扰项 | 同词性随机抽取 | 构建期预计算形近音近索引，按难度系数混合 |
| 首页 | 课程/教材入口 + 运营位 | 配速、进度、易错词、复习负载，只有一个主按钮 |
| 新词 | 直接开考或只给词表 | 先预习卡，再测验；可标为已会 |
| 反馈 | 对错 + 下一题 | 对错 + 完整词条 + 易混词 + 撤销 |
| 掌握进度 | 只有"已掌握 / 未掌握"两态 | 显示「连续正确 N」「待明日验证」，说明还差什么 |
| 复习债 | 越积越多，长期不复习自动核销 | 7 天负载可视 + 每日上限封顶，逾期只顺延、不核销 |
| 发音 | 直接把词形交给 TTS | 只朗读假名，避免多音字误读；无语音包则剔除听力题 |
| 数据 | 账号 + 云同步 | 无账号、本地存储、JSON 手动备份 |
| 商业化 | 会员、词书内购 | 无（个人项目） |

**避免雷同的具体措施**：

1. 不复用任何参考产品的图片、图标、字体或配色；
2. 页面布局顺序（今日 → 学习 → 词库 → 统计 → 设置）按"计划-执行-查阅-复盘-配置"的认知顺序自行组织，
   而非照搬"发现页 / 学习页 / 我的"三段式；
3. 交互上不模仿参考产品的滑动手势体系，改用"点选 + 键盘"双通道；
4. 命名与文案全部自拟（「言葉」「今日」「词库」「待明日验证」），不使用参考产品的产品词。

## 8. 响应式布局：手机、平板、桌面各得其所

应用不是"把手机页面拉宽"，而是三套有明确分工的布局。断点只有两条，避免维护多套分支：

| 区间 | 宽度 | 导航 | 内容 | 典型设备 |
|---|---|---|---|---|
| 手机 | < 720px | 底部导航（安全区补偿） | 单列，卡片满宽 | 手机、窄窗口 |
| 平板 | 720–1023px | 底部导航 | 单列居中，最大 820px | iPad 竖屏、小笔记本 |
| 桌面 | ≥ 1024px | 左侧栏 248px + 火漆印章 | 双列信息区，内容 1180–1240px | 笔记本、台式显示器 |

### 8.1 手机：一屏一件事

- 首页从上到下是「配速 → 今日 → 易错词 → 7 天负载 → 等级」，主按钮只有一个；
- 统计四宫格在 ≤480px 时改为 2×2，避免数字被挤成两行；
- 学习页隐藏顶栏与底部导航，只保留退出按钮，全部高度留给题目；
- 中文题干（中→日）使用正文字体而不是衬线大字，避免长释义换行后失去层级；
- 音频题用居中的圆形音频按钮，不把"听发音，选择对应的单词"当成 40px 大字标题。

### 8.2 平板：居中但不空

平板沿用手机的信息顺序，但内容区居中收窄到 820px，卡片间距放大，避免横向拉伸后每行文字过长。
学习页同样全屏专注；软键盘弹出时只隐藏底部导航，不改变题目布局。

### 8.3 桌面：侧栏 + 双列

- 左侧固定侧栏承担品牌、五个一级入口、主题切换与备份入口，顶栏只保留面包屑与状态；
- 首页左列放"复习负载 / 等级进度"，右列放"今日概览"，让首屏同时看到"做什么"和"做了多少"；
- 统计与设置使用 CSS 多列（`column-count: 2`），词库使用列表 + 详情双栏；
- 学习页进入专注模式：隐藏侧栏与顶栏，内容最大 840px 居中，键盘操作提示常驻；
- 桌面首页隐藏底部的移动端导航重复入口，避免同一功能出现两次。

### 8.4 移动端工程细节

| 问题 | 处理 |
|---|---|
| 软键盘顶起页面导致按钮移出视口 | 监听 `keyboardWillShow`，隐藏底部导航，输入区自动滚动到可视区 |
| 刘海屏/挖孔屏遮挡顶栏 | `env(safe-area-inset-top)` 补偿 |
| 底部手势条与导航栏重叠 | `env(safe-area-inset-bottom)` 补偿 |
| 触屏点按目标过小 | 最小高度 44px；选项整块可点 |
| Android 物理返回键 | 学习页先退出答题并结算；首页连按两次才退出应用 |
| WebView 不支持 speechSynthesis | 改用系统 TTS 插件；无日语语音包时自动隐藏听力题型并提示 |
| 下拉刷新误触 | `overscroll-behavior-y: none` |
| 发版后仍加载旧页面 | Service Worker 对导航请求走 network-first，静态资源走 stale-while-revalidate |

## 9. 无障碍

- 所有交互元素使用原生 `<button>` / `<input>`，保留系统焦点环与读屏语义；
- 图标按钮带 `aria-label`（如"退出学习""朗读"），不依赖图标本身表意；
- 正确/错误反馈不只靠颜色，同时有 `✓` / `✕` 符号与文字说明；
- 日语文本统一通过 `lang` 语义与注音（`ruby`）标注，便于读屏正确发音；
- 主题色对比度：正文墨色对和纸白 ≈ 13:1，朱红对和纸白 ≈ 5.2:1（满足 WCAG AA）。

## 10. 明确不做的事

- **不做账号、云同步、社交、排行榜**：个人学习工具，数据留本机是特性而非缺陷。
- **不做课程商城 / 会员**：词库已完整，不需要再卖内容。
- **不做"打卡失败惩罚"**：断签只记录，不扣进度、不发焦虑通知。
- **不做自动跳级**：熟练判定必须由真实作答与跨天验证共同满足。
- **不做长时间未复习自动核销**：间隔再长也不会被系统判为熟练；复习债用未来负载视图与每日上限管理。
- **不做自定义语料库导入**：用户自建内容无法校验释义质量与许可，且会稀释 JLPT 分级这一核心目标；
  个人补充通过词条笔记与自定义释义完成。
- **不承诺音调高低**：只把假名交给系统 TTS，没有可靠音调数据就不在界面标注，避免"标一套、读一套"。
